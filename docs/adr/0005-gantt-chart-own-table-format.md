# ガントチャートは mermaid の gantt を使わず、` ```gantt ` の独自の表形式で書く

Excel で工程表を書く代わりに、テキストでも GUI でも書けるガントチャートがほしい。mermaid の gantt はすでに描けるが、ガントチャートは ` ```gantt ` の中に `キー: 値` の設定行と、1 タスク 1 行の Markdown の表を書く独自の書式にした。表の行と GUI の表の行が 1 対 1 で対応するので、GUI で編集して書き戻しても崩れにくい。また、mermaid の gantt では書けない担当者・進捗率・メモを列として持てる。

## Considered Options

- **mermaid の gantt を GUI で編集する**: 書式を増やさずに済み、他のビューアでも描ける。ただし担当者・進捗率の列がなく、書き戻すとコメントや並びが崩れやすい
- **独自の 1 行記法（`タスクA: 2026-11-01 〜 5d @担当 50%`）**: 短く書けるが、覚える記号が増え、Excel の表との対応が見えにくい

## Consequences

- mermaid の gantt はこれまでどおり残す。ヘルプとスキルの「図を選ぶ目安」で使い分けを示す
- 他のビューア（GitHub など）では描けず、コードブロックの中の表として見える。表なので、描けなくても内容は読める
- GUI で置き換えると、ブロック全体を列幅をそろえた表に整形し直し、設定行と表以外の行は残さない。残したい文はメモ列に書く
