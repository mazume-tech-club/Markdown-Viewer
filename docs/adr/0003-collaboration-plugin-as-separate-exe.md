# 共同編集の通信は本体に入れず、別の exe（共同編集プラグイン）に分ける

拠点の違う人や在宅の人と、インターネット越しにリアルタイムで共同編集したい。ただ、使わない人も多いうえ、このアプリは「外部と一切通信せずオフラインで動作する」ことを売りにしている。そこで、インターネットとの通信はすべて別配布の exe（共同編集プラグイン）に任せ、本体には共同編集の受け口だけを持たせることにした。受け口は、エディタを Yjs で同期する部分と、プラグインと Rust 側でやり取りする部分。プラグインを入れていない本体は、今までどおり外と通信しない。

## Considered Options

- **本体に同梱して設定で ON にする**: いちばん簡単。だが、通信するコードが全員の本体に入るので「この本体は通信しない」と言い切れなくなる
- **汎用のプラグイン機構を作る（第三者もプラグインを作れる）**: 作る量が大きく、共同編集 1 つのためには重すぎる

## Consequences

- WebView の CSP（`connect-src` は IPC のみ）は緩めない。本体とプラグインの間は Rust 側でつなぎ、WebView には IPC 経由でだけ渡す
- 本体とプラグインは別々に更新されうるので、お互いの版が合っているかを接続時に確かめる必要がある
- ホストも参加者も、共同編集に加わる人は全員プラグインを入れる
- プラグインは画面を持たない Rust の exe で、通信と暗号化だけを受け持つ。Yjs の文書と、共同編集の画面（承認、参加者の一覧、カーソル、書き手の色分け）は本体の WebView に置く。プラグインが無い本体では、共同編集のメニューを表示しない
