# エクスプローラを埋め込まず、自前のファイルパネルにする

ファイルを頻繁に開き替えるため、画面右側にファイル一覧を常時表示したい。Windows のエクスプローラ（explorer.exe のウィンドウ）を Win32 API で子ウィンドウとして埋め込む案もあったが、リサイズ・フォーカス・DPI の扱いが不安定で、クリックをアプリ側で受け取れずタブで開く操作につなげられず、テーマにも追従できない。そのため、Rust 側でフォルダを列挙し WebView 上に描く自前のファイルパネルにした。

## Consequences

- 名前の変更・削除・コピーなど、エクスプローラが持つファイル操作は自分で実装しない限り使えない。最初の版は「開く」「パスをコピー」「エクスプローラーで表示」だけにしている。
