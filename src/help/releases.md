# リリースノート {#releases}

## v1.17.1（2026-10-16）
- **共同編集の参加者も画像を貼り付けられる**ようになりました。貼った画像はほかの参加者にも表示され、ホストが保存すると「ファイル名.assets」に書き出されます。1 枚 10 MB まで。後から参加した人にも、それまでに貼られた画像が届きます。参加者の「コピーとして保存」でも画像を一緒に書き出します
- 参加の要求は、画面上部のバナーではなく、画面中央の**モーダル**で「承認 / 断る」を選ぶようにしました
- 「招待リンクで参加する」の欄に入れたリンクを残すようにしました。「**クリア**」ボタンで消せます
- エディタで **`*` `-` `1.` などの箇条書きの行で Tab** を押すと、記号ごと行を字下げして入れ子にするようにしました（Shift+Tab で戻す）
- ファイルを開いていないときの案内を、**Ctrl+Shift+O**（パスで開く）にしました

## v1.17.0（2026-10-16）
- **共同編集**を追加しました。インターネット越しに 1 つのファイルを複数人で同時に編集できます。使う人は、Release の `markdown-preview-collab.exe`（共同編集プラグイン）を本体と同じフォルダに置き、**ツール → 共同編集…** から始めます。プラグインを置かなければ、これまでどおり外部と通信しません
- 中継サーバーは利用団体が自分の Cloudflare に置きます。URL は **設定 → 共同編集** に入れます。参加用の鍵による確認はまだ無いので、URL は団体の外に出さないでください

## v1.16.0（2026-10-16）
- ファイルパネルの右クリックに「**新しいフォルダ…**」を追加しました。フォルダの行ならその中、ファイルの行なら同じフォルダ、空白部分なら作業フォルダの直下に作ります。名前はツリーの中の入力欄に入れて Enter で確定します
- ファイルパネルの空白部分を右クリックすると、作業フォルダを対象にメニューを出すようにしました
- ヘルプの「Markdown 基本」に**フォルダ構成（ツリー）**の書き方を追加しました

## v1.15.0（2026-10-16）
- アプリの識別子（ID）を変更しました。設定や開いていたタブは、更新後の最初の起動でそのまま引き継がれます
- 自動更新では、これまでと同じインストール先に上書きします

## v1.14.1（2026-10-16）
- **PDF の用紙を A4** にしました（これまでは Letter でした）。「表を 1 ページに収める」も A4 の大きさで計算します

## v1.14.0（2026-10-16）
- **ターミナル**を組み込みました。画面の下か右に PowerShell を開き、作業フォルダで `claude` などを動かせます。Markdown を書き換えてもらうと、プレビューがそのまま更新されます
- 開閉はツールバーの **ターミナル**・**表示 → ターミナル**・**Ctrl+@**。置き場所はパネル上部の **右へ / 下へ** か **表示 → ターミナルの位置** で切り替えます
- パネル上部の **claude** ボタンで、そのフォルダで `claude` を起動します。Shift+Enter で改行を入力できます
- ヘルプに**リリースノート**（このページ）を追加しました。サイドバー下のバージョンをクリックしても開けます
- 以前に管理者として Program Files にインストールしていて更新できない場合は、ダウンロードの前に知らせて、ユーザーのフォルダへ入れ直す方法を案内するようにしました
